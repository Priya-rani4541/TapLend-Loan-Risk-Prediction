# Model Results and Visualizations

This folder contains selected visualizations and output screenshots from the TapLend Loan Risk Prediction and Credit Risk Analysis project.

The screenshots illustrate key stages of the analysis, including:

- Dataset overview and data preprocessing
- Exploratory data analysis
- Classification model evaluation
- Confusion matrix and classification metrics
- Decision threshold analysis
- Loan risk classification results

These results are based on the project's test dataset and are intended for educational and analytical purposes. Model predictions are estimates and should not be interpreted as confirmed future loan defaults.
